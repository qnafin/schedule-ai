# Schedule-AI

AI-ассистент для управления расписанием музыкальной школы. Ученики и преподаватели получают уведомления о занятиях в VK, администратор управляет расписанием через естественный язык, а свободные окна для репетиций публикуются в общий чат автоматически.

Проект построен вокруг **MCP-сервера** (Model Context Protocol), который отдаёт LLM-агенту доступ к расписанию, пользователям и рассылкам. Агент работает на Yandex Cloud AI Studio, канал доставки — VK, источник данных — Google Sheets.
